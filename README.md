# 👟 Nike vs Adidas Shoe Image Recognition

## 📌 Project Overview

Nike vs Adidas Shoe Image Recognition is a **Deep Learning-based image classification project** developed to identify whether a given shoe image belongs to **Nike** or **Adidas**.

The project uses image preprocessing and a **Convolutional Neural Network (CNN)** to learn visual patterns from shoe images and classify new images into the appropriate brand category.

The model was developed and trained using **Python and Google Colab**.

---

## 🎯 Objective

The main objective of this project is to develop an image recognition system that can:

- Process shoe images
- Preprocess images for deep learning
- Learn visual features from training images
- Classify shoe images into Nike or Adidas categories
- Evaluate the trained model
- Predict the brand of a new shoe image
